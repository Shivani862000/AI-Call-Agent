# P05 Recording and Callback Boundaries

**Goal:** Authenticated callbacks cannot turn recording download or playback into arbitrary network access, and every retrieval has bounded resource use.
**Spec:** [P05 remediation contract](../2026-09-08-APPLICATION_GAP_REMEDIATION_PLAN.md#p05--authenticate-callbacks-and-constrain-every-recording-fetch).
**Dependencies:** P01 isolated harness; existing legacy containment `d0f3f61` and media authorization `9710dd2`; [provider capability limits](../ICALLMATE_CAPABILITY_MATRIX.md).
**Architecture:** One streaming retrieval service validates configured origins and every DNS answer, pins the TLS connection to a validated address, and owns its deadline/byte limits. Pipeline and authenticated playback consume that service. Trusted storage uses object keys and configured storage origin.

## Global Constraints

- Existing `codex/remediation-fixes` checkout; schema stays `0019`; preserve other remediation and unrelated review documents.
- No live provider/database/storage calls, notifications, environment-file loading, pushes, merges or deployment. Use the audited P01 test harness and synthetic adapters.
- Recording/transcript/analysis access remains ADMIN-only. Authorize before lookup, retrieval or signed-URL creation; responses remain `private, no-store` including redirects and error paths.
- Empty recording origin configuration denies provider retrieval. Unknown provider support must stay explicit; do not invent signature, redirect or URL-suffix guarantees.
- Existing legacy callbacks default disabled and require the configured scalar secret when enabled. Preserve supported canonical authentication. P10 owns attempt correlation and replay safety; a shared secret alone does not complete that work.

### Task 1: Bound callback recording metadata and all retrieval paths

**Create:** `services/recording-fetch.js`, `test/recording-fetch.test.js` and focused actual route/pipeline integration tests.
**Modify:** `src/api-routes.js`, `src/icallmate-webhook.js`, `services/post-call-pipeline.js`, `services/supabase-storage.js`, configuration examples, audited test manifest.

1. Establish failing behavioral cases for both current `fetch` paths: pipeline `downloadRecording` and GET `/api/calls/:callId/recording`. Capture calls through synthetic network/storage adapters so no request escapes. Existing code directly fetches arbitrary stored URLs and buffers complete responses; the regression must exercise those callers, not only a new helper.
2. Add strict callback shape/type/length validation before mutation. Accept the explicitly supported scalar provider fields, reject arrays/objects for identifiers/status/recording references and invalid nonempty timestamps, and bound accepted bodies. Authentication must precede sensitive processing. Constrain recording metadata independently of a valid secret. Do not append `.mp3` to a complete URL or its query string; the provider contract has no verified suffix-rewrite rule. Keep external compatibility unverified until representative provider fixtures are available.
3. Parse an explicit configured list of exact HTTPS origins (including exact ports). Reject credentials, IP literals, malformed URLs and origins outside that list. Validate all resolved IPv4/IPv6 addresses against global-unicast policy, including mapped IPv4, loopback, private, link-local, metadata, multicast, unspecified and mixed safe/unsafe answers. Pin each connection to a vetted address while preserving hostname verification and TLS server name. Do not separately check DNS and then call an unpinned `fetch`.
4. Default to rejecting redirects because provider behavior is unverified. If explicit redirect support is configured, independently repeat origin/DNS/TLS validation for every hop with a hard ceiling of three redirects. No credentials are forwarded. Bound the entire request/redirect/body lifecycle to 30 seconds and 25 MiB initially; validate configurable lower limits. Reject unsupported content types, unexpected content encoding and conflicting/oversized lengths; enforce the byte bound while streaming even without a length header. These are conservative local limits, not a claim that provider capacity has been measured.
5. Make pipeline download use a unique runner/process-owned temporary filename independent of provider input, stream with backpressure, and remove partial files on failure. Keep P12 storage-based recovery separate. Make playback stream with backpressure and cancel/destroy upstream on browser disconnect or HEAD handling. Return safe fixed error summaries without signed URLs, raw provider body text or arbitrary DNS/driver messages.
6. Validate storage object keys as keys, encode path segments, and build storage requests only from trusted configured base/bucket. Signed URL responses must resolve to that configured origin and expected storage path; reject arbitrary returned origins, query/path injection and traversal. Keep authorization before signing. Add deadlines/response bounds appropriate to small signing responses, no redirect credential forwarding, and no signed-query logging.
7. Test allowed streaming, forbidden origins/addresses, IPv6/mapped forms, mixed DNS, pinned-address rebinding protection, redirect rejection/loop/limit, oversized/slow streams and cancellation. Assert forbidden requests never reach a network connector. Exercise both pipeline and actual authenticated playback, including unauthorized no-effects and stored-object signing. Tests may inject DNS/TLS connectors at the service boundary; production defaults must use the real validator and pinned connector.
8. Run affected audited suites and existing authorization/privacy/callback regressions; record counts and limitations, run `git diff --check`, commit only this task's named files and Tier 2 evidence. Controller owns the main evidence register and independent review. Do not spawn subagents.

Rollback: revert code/config changes without altering stored call records. Recording retrieval remains gated until exact provider origins and representative fixtures are verified. Callback replay and transport/disposition races remain P10 work.
